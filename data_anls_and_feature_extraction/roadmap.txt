2. 数据事实与三个必须先处理的坑（本方案的设计依据）
================================================================================
2.1 事实回顾（详见 技术路线.txt 第 1 节，均为实测）
   源域 161 个文件：
     12kHz_DE_data     60 个，96000 点（8 s），含 DE/FE/BA/RPM；其中 8 个只有 DE
     12kHz_FE_data     45 个，96000 点（8 s），1 个为 121168 点
     48kHz_DE_data     52 个，192000 点（4 s），5 个长度非整
     48kHz_Normal_data  4 个，384000 点（8 s），1 个为 243938 点
   类别：B 40 / IR 40 / OR 77（3 点 27、6 点 30、12 点 20）/ N 4
   转速：1718 ~ 1798 rpm（每文件内恒定）
   目标域 16 个文件：256000 点 = 8 s @32 kHz，变量名即文件名，无标签

2.2 坑一：**正常类只存在于 48 kHz 目录 → 采样率与类别混淆**
   161 个文件中，12 kHz 的 105 个文件只有 B/IR/OR 三类，**没有 N**；
   N 的 4 个文件全在 48kHz_Normal_data 里。
   → 若直接把 12k 与 48k 混在一起训练，模型可能靠"采样率"而不是"故障特征"
     区分正常类，得到虚高的精度。
   处理措施（本方案的解法）：
     (a) 特征层面：阶次域特征 + 无量纲时域特征本身与采样率无关，
         从根上避免混淆；
     (b) 数据层面：定义 S_48k 子集（56 个文件，四类齐全、同一采样率）
         作为"干净对照实验"，用于验证模型不是靠采样率作弊；
     (c) 验证层面：见 6.10 verify_order_domain.py，专门验证
         "12 kHz 与 48 kHz 的同故障文件能否在阶次域对齐"。

2.3 坑二：目标域没有 RPM，但题目给了"约 600 rpm"
   题目明确："列车速度约 90 km/h（轴承转速约 600 rpm）"。
   → 转频约 10 Hz，已知（近似）。
   → 目标域的转速不必盲估：以 10 Hz 为中心，在 ±15% 范围内用
     "包络谱稀疏度最大"准则做局部搜索即可（见 6.6 rpm_estimator.py）。
   这一条把原先"无键相阶次跟踪"的高风险大幅降低。

2.4 坑三：类不平衡 + 7 个非整长度文件
   OR 77 : IR 40 : B 40 : N 4。N 类占 2.5%，而正常态恰恰是目标域必须判对的类。
   → 切窗阶段做类平衡采样；任务2 用 Focal Loss + macro-F1（任务一阶段只保证
     特征表里带类别列与 file_id，便于后续平衡采样）。
   7 个非整长度文件（63788 / 121168 / 124602 / 128663 / 129969 / 130549 / 243938）
   → 切窗函数不接受固定长度，必须按实际长度计算窗数，短于一个窗的文件跳过并记录。

2.5 坑四（技术性，必须在方案里写清）：阶次域"能抹平什么、不能抹平什么"
   能抹平：故障特征频率是转频的固定倍数（BPFO/BPFI/BSF/FTF 的**阶次**只由轴承
           几何 N、d、D 决定，与转速、采样率无关）→ 包络阶次谱里的故障阶次峰
           在不同转速/采样率下位置一致，这是迁移的真正基础。
   不能抹平：冲击激发的**共振带**由结构决定、与转速无关，因此它在阶次轴上的位置
           会随转速反比移动。
   → 正确做法（本方案采用）：
       在**原生采样率**下，用谱峭度自适应选出每个域各自的共振带 → 带通
       → Hilbert 包络（包络信号是低频的） → **再**做角域重采样到统一的
       "每转 M 点" → 包络阶次谱 → 提取故障阶次特征。
     共振带差异被"自适应选带"吸收，转速差异被"阶次"吸收，两者同时解决。
   → 由此推出两条硬约束：
       (1) **不要统一下采样到 12 kHz**。那会砍掉目标域 6~16 kHz 的信息，
           属于自残。保留原生采样率，各自选带。
       (2) 角域重采样的 M 只需覆盖包络信号的低频内容（故障阶次前 20~30 阶），
           取 M = 256 点/转即可：
             源域 12k / 1800 rpm  每转约 401 点 → 满足
             目标域 32k / 600 rpm 每转约 3200 点 → 下采样，包络带宽足够
           源域 48k / 1800 rpm  每转约 1605 点 → 满足
   → 这一条也修正了 技术路线.txt 里"统一重采样"的粗说法，以本文档为准。

3. 源域筛选方案（交付物之一："筛选部分数据组成数据集"）
================================================================================
定义三个子集，主集 + 两个对照，全部由 config.py 中的一个开关选择：

  子集名      文件数  采样率    类别构成                    用途
  ----------------------------------------------------------------------------
  S_all        161    12k+48k   B40/IR40/OR77/N4            主集，特征提取全量
  S_48k         56    48k       B12/IR12/OR28/N4            干净对照：四类齐全、
                                                            同采样率，用于排除
                                                            "靠采样率区分N"的嫌疑
  S_12k_DE      60    12k       B16/IR16/OR28/N0            对照：与目标域"传感器
                                                            靠近故障"的假设最像，
                                                            但缺 N 类

  通道选择：统一取 **DE 通道**（目标域是单通道；且 DE 对驱动端与风扇端故障都有
  响应，只是远端衰减）。FE/BA 通道保留在原始文件里，本阶段不使用。

  文件级元数据（每行一个文件）：
    file_id, rel_path, domain(src/tgt), fs, n_points, duration_s, channel,
    fault_type(B/IR/OR/N), fault_size(007/014/021/028/None),
    or_position(3/6/12/None), load(0/1/2/3/None), rpm,
    source_group(12k_DE/12k_FE/48k_DE/48k_Normal)

  筛选理由要写进报告：
    - 选 DE：与目标域单通道、且传感器靠近故障的假设一致；
    - 保留 OR 的三个点位（3/6/12 点钟）：提供"故障相对载荷方向位置"的域多样性；
    - 保留 12k 与 48k：提供"采样率"的域多样性（用于跨域代理任务）；
    - 不引入外部数据集：保证类别空间完整（含滚动体 B），避免负迁移。

4. 特征体系设计
================================================================================
四组特征，输出到同一张表里，用列名前缀区分（t_/f_/o_/tf_），便于任务2/3 消融。

4.1 机理层（不是特征，是"标尺"）
    按表 1 参数 + 各文件 RPM 计算 BPFO/BPFI/BSF/FTF 的**频率**与**阶次**：
      SKF6205（DE）: N=9, d=0.3126 in, D=1.537 in
         → BPFO 阶次 ≈ 3.585, BPFI ≈ 5.415, BSF ≈ 2.357, FTF ≈ 0.398
      SKF6203（FE）: N=9, d=0.2656 in, D=1.122 in
         → BPFO 阶次 ≈ 3.435, BPFI ≈ 5.565, BSF ≈ 1.991, FTF ≈ 0.382
    用途：(a) 验证源域包络谱里确实出现这些峰（机理证据）；
          (b) 作为阶次域特征提取的"字典"；
          (c) 反推目标域轴承的疑似故障阶次（目标域几何未知）。

4.2 时域特征（t_*，12 个）
    均值、标准差、方差、RMS、峭度、偏度、峰值、峰峰值、峰值因子、脉冲因子、
    裕度因子、波形因子。
    量纲的（RMS/峰值/峰峰值）需归一化；无量纲的（峭度、因子类）直接可比。

4.3 频域与包络谱特征（f_*）
    - 频谱统计：谱重心、均方频率、频率方差、谱峭度、谱熵、主频
    - 包络谱：Hilbert 平方包络 → FFT
    - 故障频率比：各理论故障频率处幅值 / 总能量、2~4 次谐波能量占比
    **用途限制（重要）**：绝对频率类特征（谱重心、主频、故障频率处的绝对幅值）
      依赖转速与采样率，**跨域不可比**。因此 f_* 只用于任务2（源域诊断）
      与"机理验证图"，**不作为任务3 的迁移特征**。这一点会在列名与
      dataset_card.txt 中显式标注。

4.4 阶次域特征（o_*，迁移主力）
    流程见 2.5 节。输出固定长度向量：
      - 各理论故障阶次（及 2/3/4 次谐波）邻域（±3%）的峰值
      - 峰值 / 邻域中位数之比（突出"尖峰"而非"整体能量"）
      - 故障阶次带能量 / 全谱能量
      - 包络阶次谱的稀疏度、负熵、谱峭度
      - 转频阶次（1×、2×、3×）处幅值（用于识别内圈/滚动体故障的调制）
    这些量与采样率、转速无关，**源域与目标域可直接比** → 任务3 的主特征。

4.5 时频图表征（tf_*，供任务2 的 2D-CNN，P1）
    STFT（P0 可用 scipy）或 CWT（需 PyWavelets）。
    **跨域尺度一致性**：在带通包络信号上生成，或先生成再按"每转点数"归一化，
    否则源域与目标域的时频图尺度不一致，2D-CNN 学不到可迁移的纹理。
    输出统一尺寸（默认 64×64）的 float32 数组。

5. 预处理与切窗规范（防泄漏，写进 config.py）
================================================================================
  - 去直流 / 去线性趋势；
  - **不统一重采样**（理由见 2.5）；各域在原生采样率下处理；
  - 两种窗长预设，用途不同：
      WIN_SEC_SIGNAL  = 0.128 s  → 供端到端信号型模型（样本多）
      WIN_SEC_FEATURE = 0.5   s  → 供阶次谱/包络谱特征（阶次分辨率够）
    选择理由：
      0.128 s @600 rpm 覆盖约 4.6 个 BPFO 冲击周期（BPFO≈35.8 Hz，周期 28 ms）；
      0.5 s @600 rpm = 5 转，包络阶次谱的阶次分辨率为 1/5 = 0.2 阶，
      足以分开 BPFO(3.58) 与 BSF(2.36)（相差 1.2 阶）。
  - 重叠：**训练用 50% 重叠，测试/标定用不重叠**；
  - **每个窗必须携带 file_id**；
  - 划分单位是"文件"，由 build_dataset.py 输出 splits.json
    （按 类别 × 故障尺寸 × 载荷 分层，5 折，同文件不跨折）；
  - 类平衡采样只在"读表训练"时做，不在特征提取时丢弃数据。

  预计样本量（已按实测长度算好）：
    窗长 0.128 s，50% 重叠：源域约 16492 窗；目标域 1984 窗
    窗长 0.5   s，50% 重叠：源域约  4095 窗；目标域  496 窗
    窗长 0.5   s，不重叠  ：源域约  2128 窗；目标域  248 窗

--------------------------------------------------------------------------------
7.3  data_loader.py
--------------------------------------------------------------------------------
  作用：把 179 个 .mat 变成结构化元数据 + 按需读取信号。**只在这里处理文件名
        解析与变量名不固定的问题**，其它模块不碰原始文件。
  关键函数：
    parse_filename(fname, group) -> dict
        解析规则（覆盖全部实测命名）：
          B007_0.mat           → B,   size 007, load 0
          IR014_2.mat          → IR,  size 014, load 2
          B028_0_(1797rpm).mat → B,   size 028, load 0, rpm 1797
          OR007@6_0.mat        → OR,  size 007, pos 6,  load 0
          OR007@3_1.mat        → OR,  size 007, pos 3,  load 1
          OR007@12_2.mat       → OR,  size 007, pos 12, load 2
          N_0.mat / N_1_(1772rpm).mat → N, load 0/1, rpm 1772
    scan_source() -> list[dict]   遍历 源域数据集，返回 161 条记录
    scan_target() -> list[dict]   返回 16 条记录（file_id=A..P, label=None）
    load_signal(rec, channel='DE') -> (x: np.ndarray float64, fs, rpm)
        变量名不固定（X118_DE_time / X119_DE_time …），用后缀匹配
        "_DE_time" / "_FE_time" / "_BA_time" / "RPM"；
        8 个只有 DE 变量的 12k 文件、48k 无 BA 的情况都要能正常返回；
        rpm 取自文件内 RPM 变量，缺失时回退到文件名里的 (1797rpm) 或元数据。
  注意：
    - **不缓存大数组**，每次按需读取，避免 161 个文件全部驻留内存
      （源域总点数约 2.1e7，全读进来约 170 MB，但加上重复通道会更大）；
    - 文件名里含中文路径，统一用 pathlib + UTF-8。
  依赖：config, scipy.io, numpy, pathlib, re。

--------------------------------------------------------------------------------
7.4  data_audit.py
--------------------------------------------------------------------------------
  作用：任务一"数据分析"的第一份硬证据。产出一张审计表 + 一份摘要。
  关键函数：
    audit_source() / audit_target() -> pandas.DataFrame
        列：file_id, rel_path, group, fs, n_points, duration_s,
            channels(逗号分隔), has_rpm, rpm, fault_type, fault_size,
            or_position, load, is_irregular(bool)
    summarize() -> str
        类别 × 采样率 交叉表；类别 × 载荷；类别 × 故障尺寸；
        转速分布；非整长度文件清单；类不平衡比例；

    outputs/audit_target.csv（16 行）
    outputs/audit_summary.txt
    figures/audit_class_dist.png    类别×采样率 堆叠柱状图
    figures/audit_rpm_dist.png      转速分布
  依赖：config, data_loader, pandas, matplotlib, seaborn。

7.5  bearing_kinematics.py
--------------------------------------------------------------------------------
  作用：把"轴承故障机理"变成可计算的标尺。
  关键函数：
    fault_orders(N, d, D) -> dict

7.6  rpm_estimator.py
--------------------------------------------------------------------------------
  作用：**只给目标域用**。源域有 RPM 变量，不需要估计。
  思路：题目已知目标域转速约 600 rpm（转频约 10 Hz）→ 在 (1±15%) 内搜索 f_r，
        对每个候选 f_r 做角域重采样并计算包络阶次谱的**稀疏度/负熵/峭度**，
        取准则最优者。理由：转速估错时，故障冲击在阶次谱上会"抹开"，
        谱越稀疏（越尖锐）说明 f_r 越准。
  关键函数：
    coarse_search(x, fs, f_lo, f_hi, step) -> (best_fr, curve)
    refine_search(...)                     两级细化：0.1 Hz → 0.02 Hz
    estimate_target_rpm_batch(records) -> DataFrame
        对 16 段分别估计，并统计离散度（若离散度大 → 说明各段转速不同，
        报告中必须说明，且角域重采样要逐段用各自的 f_r）
    stability_report()  → 16 段估计值的均值/标准差/箱线图
  输出：outputs/target_rpm.csv, figures/target_rpm_search.png
  依赖：config, data_loader, preprocess（角域重采样）, features_order, numpy。

7.7  preprocess.py
--------------------------------------------------------------------------------
  作用：所有信号级的公共操作集中于此，保证各特征模块口径一致。
  关键函数：
    detrend_dc(x)                     去均值 + 去线性趋势
    bandpass(x, fs, band)             scipy.signal.butter + filtfilt（零相位）
    hilbert_envelope(x)               解析信号取模 → 包络
    resample_angular(x, fs, fr, m_per_rev=256)
        角域重采样：按转速把时间序列插值到等角度采样
        实现：由 fr 构造瞬时相位 θ(t)=2π·fr·t（fr 恒定），
              目标角度栅格 θ_k = 2π k / m_per_rev，
              用 np.interp 在 θ 上线性插值 → 输出等角度序列
        **注意**：这是恒转速下的简化 COT；若目标域转速有波动，
                 在任务三再升级为时频脊线法（现在不做，避免过度设计）
    normalize(x, mode='zscore')        窗内 z-score / 最大幅值归一化
    segment(x, fs, win_sec, overlap)   **按秒**切窗，返回 (n_win, win_len)
        非整长度文件自适应：窗数 = floor((n - win_len)/step) + 1，
        不足一窗则跳过并记录到 skipped 列表
    make_windows(rec, win_sec, overlap, channel) -> (windows, meta)
        每个窗附带 file_id / 窗内起止点，供后续追溯
  依赖：config, scipy.signal, numpy。

7.10 features_order.py   ★迁移主特征★

  作用：把"转速与采样率差异"从特征层面消除，产出源域与目标域可直接比较的

  关键函数：
    to_order_domain(env, fs, fr, m_per_rev) -> 等角度包络序列
