0. 全局符号与命名约定
================================================================================

0.1 故障类别 fault_type
    B   滚动体故障（Ball）
    IR  内圈故障（Inner Race）
    OR  外圈故障（Outer Race）
    N   正常（Normal）

0.2 故障尺寸 fault_size
    007 / 014 / 021 / 028，单位是 0.001 英寸，即 0.007、0.014、0.021、0.028 英寸。
    **注意：CSV 里存成数值 7 / 14 / 21 / 28（浮点，显示为 7.0）**，不是 0.007。
    原因：同一列里 N 类没有故障尺寸（NaN），pandas 会把整列变成 float。
    覆盖情况：OR 只有 007/014/021 三种；B 与 IR 有四种；N 没有。

0.3 外圈故障位置 or_position
    3  = 3 点钟方向（Orthogonal，正交于载荷）
    6  = 6 点钟方向（Centered，正对载荷）
    12 = 12 点钟方向（Opposite，背对载荷）
    仅 OR 类有该字段，其余为 NaN。

0.4 载荷 load
    0 / 1 / 2 / 3，单位马力（hp）。对应源域目录里文件名末尾的下划线数字，
    例如 B007_0 的 0 就是载荷 0。

0.5 源域分组 group
    12k_DE       12 kHz 采样、驱动端轴承故障（传感器也在驱动端）
    12k_FE       12 kHz 采样、风扇端轴承故障（故障与传感器分处两端）
    48k_DE       48 kHz 采样、驱动端轴承故障
    48k_Normal   48 kHz 采样、正常状态（**N 类只存在于这个分组**）
    target       目标域（真实列车轴承）

0.6 采样率 fs
    源域 12 kHz 或 48 kHz；目标域 32 kHz。单位 Hz。

0.7 轴承与"阶次"
    N  滚动体个数（本数据两个轴承都是 9）
    d  滚动体直径（英寸）
    D  轴承节径（英寸）
    fr 转频 = rpm / 60，单位 Hz

    四个故障特征频率（Hz）：
      BPFO 外圈故障特征频率 = fr · (N/2) · (1 - d/D)
      BPFI 内圈故障特征频率 = fr · (N/2) · (1 + d/D)
      BSF  滚动体故障特征频率 = fr · (D/2d) · [1 - (d/D)^2]
      FTF  保持架（滚动体公转）频率 = fr · 0.5 · (1 - d/D)

    **阶次 order = 特征频率 / fr**，所以阶次只由 N、d、D 决定，与转速无关：
      SKF6205：BPFO 3.5848 / BPFI 5.4152 / BSF 2.3567 / FTF 0.3983
      SKF6203：BPFO 3.4348 / BPFI 5.5652 / BSF 1.9938 / FTF 0.3816
    这是整套迁移方案的物理基础：转速从 1800 rpm 变到 600 rpm 时，频率会平移，
    但阶次不变。因此把特征建在"阶次轴"上就能跨转速、跨采样率比较。

0.8 信号处理链上的几个术语
    包络 envelope      对带通信号做 Hilbert 变换取模，得到幅值包络
    包络谱             对包络做 FFT，故障冲击会表现为特征频率处的尖峰
    EOS                包络阶次谱 = 把包络信号按"等角度"重采样后再做 FFT，
                       横轴单位是阶次而不是 Hz
    角域重采样         按每转固定点数（本项目 256 点/转）重新采样，
                       把"时间轴"换成"角度轴"
    SK / 峭度图        谱峭度（Spectral Kurtosis），用来自动找出冲击最明显的
                       共振频带，本项目用它选带通区间
    谱峭度选带 band_lo/band_hi  自动选出的带通上下限，单位 Hz

0.9 窗（window）与切窗参数
    信号窗 0.128 s   供端到端信号型模型用的短窗（本次未导出大文件）
    特征窗 0.5 s     所有特征都在这个窗上算；源域 12k 为 6000 点，
                     48k 为 24000 点，目标域 32k 为 16000 点
    重叠 overlap     本次用 0.5（50%），即步长 0.25 s；
                     同一文件的窗高度相关，因此**划分单位必须是文件**
    win_idx          该窗在该文件内的序号，从 0 开始
    win_start        该窗在原始信号里的起始采样点索引

0.10 特征列命名规范（最重要的一条）
    前缀 t_       时域特征（time）
    前缀 f_       频域与包络谱特征（freq）
    前缀 o_       阶次域特征（order），**跨域可迁移的主力特征**
    前缀 o_theo_  阶次域中的"理论阶次"特征，**只有源域有**
                  （目标域轴承几何未知，算不出理论阶次 → 该列为 NaN/不存在）
    后缀 _rel     该特征除以"同一文件的中位数"，用于消除设备增益/量纲差异
                  （只有 6 个量纲类时域特征有）

    **可否用于任务三迁移：**
      可用：全部 t_*（尤其无量纲的与 *_rel）、全部 o_*（不含 o_theo_）
      不可用：全部 f_*（含绝对频率，随转速和采样率变化）、o_theo_*（只有源域有）
    共 49 个可迁移特征。这条规则写在 dataset_card.txt 里。

0.11 显著性/统计量
    mutual_info  互信息，≥0，越大说明该特征对类别的区分能力越强
    fisher_ratio Fisher 判别比 = 类间方差 / 类内方差，越大越可分
    spearman_rho Spearman 秩相关系数，范围 [-1,1]，越接近 0 说明与转速越无关
    ks_stat      Kolmogorov-Smirnov 两样本统计量，范围 [0,1]，
                 0 = 两个分布完全一致，1 = 完全不重叠；越小说明域差异越小
    prom_*       显著性 = (曲线最大值 - 曲线中位数) / 曲线标准差

2.1  audit_source.csv —— 源域文件级审计表（161 行 × 18 列，1 行 = 1 个 .mat 文件）
--------------------------------------------------------------------------------
生成脚本：data_audit.py

  file_id        字符串。相对路径去掉 .mat 后的唯一标识，
                 例：12kHz_DE_data/B/0007/B007_0。全项目用它做文件主键。
  domain         恒为 "src"。
  group          源域分组，取值为 12k_DE / 12k_FE / 48k_DE / 48k_Normal。
  fs             采样率 Hz，12000 或 48000。
  n_points       该文件 DE 通道的采样点数（96000 / 192000 / 384000 / 其他）。
  channels       该文件包含的时域通道，逗号分隔：
                 "DE,FE,BA"（97 个）、"DE,FE"（56 个）、"DE"（8 个）。
  bearing        被判定的故障轴承型号：
                 SKF6205（驱动端故障，12k_DE / 48k_DE / 48k_Normal）
                 SKF6203（风扇端故障，12k_FE）
                 注意：型号按"哪个轴承坏了"判定，与用哪个通道读数无关。
  fault_type     B / IR / OR / N。
  fault_size     7 / 14 / 21 / 28（即 0.007~0.028 英寸，见 0.2）；N 类为 NaN。
  or_position    3 / 6 / 12，仅 OR 类有值，其余 NaN。
  load           0 / 1 / 2 / 3（马力）。
  rpm_filename   仅从**文件名括号**里解析出的转速，例如
                 B028_0_(1797rpm) → 1797；没有括号标注的为 NaN。
  duration_s     = n_points / fs，单位秒。
  has_rpm_var    True/False。文件内部是否含有 RPM 变量。
  rpm            该文件最终采用的转速（优先取文件内 RPM 变量，
                 其次取 rpm_filename），单位 rpm。
  rpm_source     rpm 的来源："var"（文件内变量，151 个）或
                 "filename"（文件名标注，10 个）。
  is_irregular   True/False。点数不属于 {96000,192000,384000,256000}
                 即为异常长度。共有 7 个 True，需在做长度敏感操作时注意。
  subset_tags    该文件归属的数据子集，分号分隔：
                 S_all（全部 161）、S_48k（56，四类齐全且同一采样率）、
                 S_12k_DE（60，缺 N 类）。

  用途：① 论文里"数据情况"一节的表格来源；② 后续任何脚本筛选文件的依据；
        ③ 排查异常文件的清单。

2.5  target_rpm.csv —— 目标域转速估计结果（16 行 × 12 列）
--------------------------------------------------------------------------------
生成脚本：rpm_estimator.py。题目已给出目标域"约 600 rpm"，本表是
"用数据独立验证这个先验"的结果。

  file_id      A ~ P
  fs           32000
  band_lo      谱峭度自动选出的共振带下限（Hz）
  band_hi      共振带上限（Hz）
  fr_prior     先验转频 = 600/60 = 10.0 Hz（题目给定值）
  fr_hps       HPS（谐波积谱）法估计的转频。做法是在低频段找
               "1×、2×…5× 都存在峰"的那个基频，属于与故障无关的独立估计。
  prom_hps     HPS 得分曲线的显著性 =(max-median)/std。
              本项目阈值取 3.0；≥3.0 认为该估计可信。
  fr_comb      梳状搜索估计的转频：假定故障特征阶次族在 [2.4, 5.0] 之间，
               搜索使包络谱上"族内谐波能量最大"的转频。
  prom_comb    梳状得分的显著性（普遍偏低，因为阶次与转频存在耦合，
               所以本表最终以 HPS 为主、梳状仅作参考）
  fr_final     最终采用的转频（Hz）
  rpm_final    = fr_final × 60，最终采用的转速（rpm）
  method       最终值来自哪种方法："hps" / "comb" / "prior"
               本次结果：15 段用 hps、1 段（C）置信度不足回退 prior

  本次结果：15 段估计在 576.0~577.8 rpm，均值 578.44，标准差 5.77（1.00%）。
  这独立印证了题目"约 600 rpm"的说法，且证明各段转速基本一致。

2.6  verify_order_align.csv —— 门禁 H1：跨采样率阶次对齐（9 行 × 9 列）
--------------------------------------------------------------------------------
生成脚本：verify_order_domain.py。
做法：取"同一故障类型 + 同一故障尺寸 + 同一载荷"在 12k 与 48k 下的一对文件，
      各自算包络阶次谱，看同一故障特征的峰是否落在同一阶次位置。

  pair                 配对标识，如 B007_load0
  fault                故障类型 B/IR/OR（决定看哪个特征阶次）
  key_order            该类型对应的主特征阶次名：
                       B → BSF，IR → BPFI，OR → BPFO
  theo                 该特征的理论阶次
  order_12k            12 kHz 文件在理论阶次邻域内实测峰值所在阶次
  order_48k            48 kHz 文件对应的实测峰值阶次
  rel_gap_12k_48k      = |order_12k − order_48k| / theo，跨采样率的相对偏差
  dev_from_theory_12k  = |order_12k − theo| / theo，与理论值的相对偏差
  dev_from_theory_48k  = |order_48k − theo| / theo

  判据：rel_gap ≤ 0.05（5%）算通过；整体用**中位数**判定。
  本次结果：总体中位偏差 0.0186 → 判定 PASS。
  分类型中位偏差：IR 0.0000、OR 0.0005、B 0.1437。
  → 内圈与外圈的阶次对齐非常好；**滚动体（BSF）是唯一异常项**，
    因为它本身是最弱的特征（冲击幅值小、调制复杂），
    后续任务中 B 类应被视为最不可靠的一类。


--------------------------------------------------------------------------------
2.7  verify_speed_variation.csv —— 门禁 H1b：跨转速阶次对齐（11 行 × 8 列）
--------------------------------------------------------------------------------
同源文件、同一故障在不同载荷（因此转速不同）下，阶次位置是否一致。
这是"阶次域能消除转速差异"的直接验证。

  group        故障组标识，如 B007（故障类型 + 尺寸）
  order_key    同 2.6
  rpm_low      该组内最低转速
  rpm_high     该组内最高转速
  order_low    rpm_low 文件实测的峰值阶次
  order_high   rpm_high 文件实测的峰值阶次
  theo         理论阶次
  rel_gap      = |order_low − order_high| / theo

  本次结果：中位相对偏差 **0.0101（1%）**，转速从 1718 变到 1797 rpm
  （跨度约 4.6%）而阶次几乎不动 → 转速不变性成立，阶次域方案有效。


--------------------------------------------------------------------------------
2.8  verify_report.txt —— 门禁结论报告
--------------------------------------------------------------------------------
5 节：
  [H1]   跨采样率的阶次对齐表 + 分类型中位偏差 + 判定（PASS/FAIL）
  [H1b]  跨转速的阶次对齐表 + 中位偏差
  [H2]   目标域转速估计稳定性：n、均值、标准差、相对标准差、各方法计数、判定
         判据：相对标准差 < 3% 判 PASS（本次 1.00% → PASS）
  [note] 阶次分辨率说明：阶次分辨率 = 1 / 窗内转数。
         源域 0.5 s @1800 rpm ≈ 15 转 → 0.067 阶（细）
         目标域 0.5 s @600 rpm ≈ 5 转 → 0.200 阶（粗，理论阶次 ±3% 只有约 1 个
         频率格，因此目标域更依赖 o_pk*_order 这类"找峰"特征而不是固定阶次窗口）
  [退路] 若 H1 不通过时的备选方案（改用无量纲时域特征 + 相对频带能量比）

  用途：这是任务一"方法有效性"的自我验证记录，可直接作为论文中
        "为什么用阶次域"的论据。**这个脚本是流水线的门禁，必须先跑。**

2.9  features_source.csv —— 源域窗级特征总表（4120 行 × 102 列）★主产物★
--------------------------------------------------------------------------------
生成脚本：build_dataset.py。**1 行 = 1 个 0.5 s 的窗**，任务二/三的主输入。

列分五组：11 个元数据/标签列 + 18 个 t_ + 16 个 f_ + 37 个 o_ + 20 个 o_theo_

【A 组：元数据与标签（11 列）】
  domain        恒为 "src"
  file_id       所属文件（用于按文件划分，防止泄漏）
  group         源域分组（12k_DE / 12k_FE / 48k_DE / 48k_Normal）
  fs            采样率 Hz
  win_idx       窗在该文件内的序号（0 起）
  win_start     窗起点在原始信号中的采样点索引
  rpm           该文件转速
  fault_type    标签：B/IR/OR/N
  fault_size    7/14/21/28（0.001 英寸）
  or_position   3/6/12，非 OR 类为 NaN
  load          0/1/2/3 马力

【B 组：时域特征 t_*（18 列 = 12 个基础 + 6 个 _rel）】
  （窗内已先去均值；x 表示窗内序列）
  t_mean_abs    平均绝对幅值  mean(|x|)
  t_rms         均方根        sqrt(mean(x²))
  t_std         标准差
  t_var         方差
  t_peak        峰值          max(|x|)
  t_p2p         峰峰值        max(x) − min(x)
  t_kurtosis    峭度（Fisher 形式，正态分布为 0；故障冲击会显著增大）
  t_skewness    偏度（分布不对称程度）
  t_crest       峰值因子 = t_peak / t_rms          （无量纲）
  t_impulse     脉冲因子 = t_peak / t_mean_abs      （无量纲）
  t_clearance   裕度因子 = t_peak / (mean(sqrt|x|))²（无量纲）
  t_shape       波形因子 = t_rms / t_mean_abs       （无量纲）
  t_mean_abs_rel  t_mean_abs 除以"同一文件该特征的中位数"
  t_rms_rel       t_rms  的同上归一化
  t_std_rel       t_std  的同上归一化
  t_var_rel       t_var  的同上归一化
  t_peak_rel      t_peak 的同上归一化
  t_p2p_rel       t_p2p  的同上归一化
  ★ 前 6 个是**量纲特征**，源域与目标域的绝对幅值差 40 倍以上
    （实测域间 KS = 0.97），**不能直接用于迁移**；
    *_rel 版本把每台设备自身的增益除掉后，域间 KS 降到 0.065，是可迁移的。
  ★ 后 6 个无量纲特征本身就与量纲无关，可直接跨域比较。

【C 组：频域与包络谱特征 f_*（16 列）】
  先算幅值谱 A(f)（加 Hann 窗），P = A²：
  f_centroid    谱重心 = Σ f·P / Σ P，单位 Hz
  f_msf         均方频率 = Σ f²·P / Σ P，单位 Hz²
  f_rmsf        均方根频率 = sqrt(f_msf)，单位 Hz
  f_variance    频率方差 = Σ (f−重心)²·P / Σ P，单位 Hz²
  f_peak_freq   主频（幅值谱最大点对应的频率），单位 Hz
  f_entropy     谱熵 = −Σ p·ln p（p 为归一化功率谱），反映谱的平坦程度
  f_spec_kurt   幅值谱的峭度
  f_env_log_energy  包络谱总功率的 log10，反映包络能量量级
  对每个特征频率 X ∈ {BPFO, BPFI, BSF, FTF}：
  f_X_ratio1        = 该频率邻域（±2%）内包络谱峰值 / 包络谱总能量
  f_X_harm_frac     = 1~4 次谐波邻域峰值之和 / 包络谱总能量

  ★ 这一组全部含**绝对频率**，随转速和采样率变化，
    **不可用于任务三迁移**，只用于源域诊断（任务二）与机理验证图。

【D 组：阶次域特征 o_*（37 列）★迁移主力★】
  由"包络阶次谱 EOS"导出，EOS 已在 0.5~32 阶范围内归一化（总能量为 1）。

  前 24 列：按幅值从大到小排名前 8 个峰，每个峰 3 个属性：
    o_pkK_order  第 K+1 大峰所在的**阶次**（K = 0…7）
    o_pkK_amp    该峰的归一化幅值（峰功率 / EOS 总功率）
    o_pkK_ratio  该峰 / EOS 的中位数（峰-背景比，突出"尖峰"而非整体能量）
    ★ 这 24 列**不依赖轴承几何**，源域与目标域结构完全一致，
      是本次分析中互信息最高的一组（o_pk0_order 互信息 0.78）。

  中间 4 列：EOS 整体形状
    o_entropy   阶次谱熵（越小越"尖"，说明周期冲击越明显）
    o_kurtosis  阶次谱峭度
    o_crest     阶次谱峰值因子 = 最大值 / 均值
    o_gini      阶次谱 Gini 系数（0=能量均匀，1=能量集中在少数阶次）

  再 5 列：阶次频带能量占比
    o_bandfrac0  阶次 [0.5, 1.5)  能量占比
    o_bandfrac1  阶次 [1.5, 3.0)  能量占比
    o_bandfrac2  阶次 [3.0, 6.0)  能量占比 ← BPFO(3.58)/BPFI(5.42) 落在这里
    o_bandfrac3  阶次 [6.0, 12.0) 能量占比
    o_bandfrac4  阶次 [12.0, 32.0) 能量占比

  最后 4 列：转频及其倍频（内圈/滚动体故障的幅值调制证据）
    o_shaft1    1× 转频阶次处的归一化幅值
    o_shaft2    2× 转频阶次处
    o_shaft3    3× 转频阶次处
    o_shaft21   = o_shaft2 / o_shaft1

【E 组：理论阶次特征 o_theo_*（20 列，仅源域有）】
  对每个特征 X ∈ {BPFO, BPFI, BSF, FTF}：
    o_theo_X_1_ratio ~ o_theo_X_4_ratio
        第 1~4 次谐波阶次邻域（±3%）的峰值 / 该邻域扩大范围（±15%）的
        背景中位数。>1 表示该处确有超出背景的峰。
    o_theo_X_frac
        第 1~4 次谐波峰值之和 / EOS 总能量。
  ★ 这一组需要已知轴承几何。**目标域缺这 20 列**，所以
    features_target.csv 只有 82 列。任务二用它们，任务三不能用。

  用途：任务二（源域诊断）直接读本表；任务三（迁移）只取 49 个可迁移列。

2.11 splits.json —— 按文件的 5 折划分索引
--------------------------------------------------------------------------------
结构：
  { "0": {"test": [file_id, ...], "train": [file_id, ...]},
    "1": {...}, ... "4": {...} }

  - 键是折号 "0"~"4"；每折给出该折的测试文件列表与其余全部训练文件列表。
  - **划分单位是文件**，同一文件的 31 个窗绝不会同时出现在训练和测试里
    —— 这是防止重叠窗造成数据泄漏的关键。
  - 分层方式：先按 fault_type 分组，组内打乱后按 fold 轮转分配，
    因此每折的类别构成尽量均衡。
  - 本次各折文件数：33 / 33 / 32 / 32 / 31；
    N 类只有 4 个文件，所以折 0~3 各 1 个 N，**折 4 没有 N**，
    在折 4 上算指标时要注意 macro-F1 的类别集合。

  用途：任务二训练/评估时直接读取，禁止自行随机切分。

4. 常见疑问
================================================================================
Q1 为什么 fault_size 显示 7.0 而不是 0.007？
   见 0.2。列里含 NaN 导致 pandas 把整数列转成 float；数值 7 表示 0.007 英寸。

Q2 为什么 features_target.csv 列数比 source 少 20？
   缺的是 o_theo_* 20 列，它们需要已知轴承几何（N、d、D），目标域未知。

Q3 为什么目标域那一堆标签列都是 NaN？
   题目明确"各数据所属工作状态未知"，这正是任务三要预测的对象。

Q4 t_rms 和 t_rms_rel 该用哪个？
   做任务三迁移必须用 *_rel；t_rms 这种绝对幅值在源域内部的诊断
   （任务二）里可以用，但跨域会直接失效（域间 KS 0.97）。

Q5 o_* 和 f_* 有什么区别？
   o_* 建在"阶次轴"上（= 频率/转频），与转速、采样率无关，可迁移；
   f_* 建在"Hz 轴"上，转速一变位置就变，不可迁移，只服务源域诊断。

Q6 为什么 splits.json 的第 4 折没有 N 类样本？
   N 类只有 4 个文件而折数是 5。若强行 5 折等分，必须拆文件（不允许）；
   因此允许某一折缺 N，并在该折上改用"实际出现的类别"计算 macro-F1。

Q7 timefreq_demo.npz 能直接拿去训练吗？
   不能，只有 7 个样例。需要完整时频图时用 build_dataset.py --save-timefreq。

Q8 数据泄漏怎么防的？
   三重保险：① 窗级特征表带 file_id；② splits.json 按文件划分；
   ③ dataset_card.txt 明确要求"禁止把同一文件的窗随机分到两侧"。

Q9 cache 能删吗？删了会怎样？
   能删。删掉后下次 run.py 会重新计算全部特征（首次约 65 s）。

Q10 为什么 H1 里滚动体(B)偏差大，但整体还是判 PASS？
   因为判据用中位数，且 IR/OR（内圈/外圈）的偏差是 0.0000 / 0.0005，
   非常干净。BSF 本身是轴承里最弱、最易被噪声淹没的特征，
   这是物理限制而非流程错误 —— 但意味着**B 类的迁移结果可信度最低**，
   任务三给出标签时应把 B 类的置信度单独说明。
