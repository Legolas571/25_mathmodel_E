0. 通用约定（读任何一张图之前先看这节）
================================================================================

0.1 为什么所有标注都是英文
    绘图环境缺少中文字体，中文会显示成方块，因此图内标题、坐标轴、图例一律用
    英文。本文件给出每一处英文标注的中文对照。

0.2 全局配色约定
    蓝色        源域 12 kHz 驱动端数据（12k_DE）／源域散点
    橙色        源域 48 kHz 驱动端数据（48k_DE）
    红色        目标域（真实列车轴承）／先验参考线
    绿色        阶次域特征（o_*）
    灰色        时域特征（t_*）
    黑色虚线    理论值（机理计算得到的特征阶次／频率）或先验值（600 rpm）

0.3 三类坐标轴
    频率轴 Hz      只在"包络谱"类图里出现，随转速变化，**跨域不可直接比较**
    阶次轴 order   频率 ÷ 转频，与转速、采样率无关，**跨域可比较**
    计数轴        文件数／样本数

0.4 箱线图读法（analysis_feature_boxplots 用到）
    箱内横线    中位数
    箱体上下边  第 25 / 75 百分位（Q1 / Q3），箱体高度 = 四分位距 IQR
    须线上下端  Q1 − 1.5×IQR 与 Q3 + 1.5×IQR
    离群点      **已用 showfliers=False 隐藏**，所以图上看不到孤立点

0.5 三个反复出现的符号
    EOS   包络阶次谱（envelope order spectrum）
    theo  理论值（theoretical）
    rpm   每分钟转数；fr = rpm/60 为转频（Hz）

0.6 图与脚本的对应
    data_audit.py           → audit_class_dist.png、audit_rpm_dist.png
    rpm_estimator.py        → target_rpm_search.png、target_rpm_estimate.png
    verify_order_domain.py  → verify_order_align_*.png（9 张）
    features_freq.py        → mechanism_env_spectrum_*.png（4 张）
    features_timefreq.py    → timefreq_samples.png
    analysis_report.py      → analysis_*.png（4 张）

图 1  audit_class_dist.png —— 类别分布与采样率混淆
--------------------------------------------------------------------------------
结构：左右两个子图。

【左图】标题 "Source: class x group"（源域：类别 × 分组）
  x 轴  fault type       故障类别，取值 B / IR / OR / N
  y 轴  file count       文件个数
  堆叠色块按 group（源域分组）分 4 类，图例见右上角：
        12k_DE（蓝）     12 kHz、故障在驱动端
        12k_FE（红）     12 kHz、故障在风扇端
        48k_DE（粉）     48 kHz、故障在驱动端
        48k_Normal（浅蓝）48 kHz、正常状态
  本次读数：
        B  共 40 = 16 + 12 + 12 + 0
        IR 共 40 = 16 + 12 + 12 + 0
        OR 共 77 = 28 + 21 + 28 + 0
        N  共  4 =  0 +  0 +  0 + 4
  结论：N 类完全落在 48k_Normal 这一格里，其余三类没有 48 kHz 的正常样本。

【右图】标题 "Source: class x sampling rate (N only at 48 kHz)"
        （源域：类别 × 采样率（正常样本只在 48 kHz））
  x 轴  fault type       同上
  y 轴  file count       同上
  堆叠色块按 fs_khz（采样率）分 2 类：
        12 kHz（绿）、48 kHz（灰）
  本次读数：
        B   28 / 12        IR  28 / 12
        OR  49 / 28        N    0 / 4
  结论：**这是任务一最重要的数据发现之一**。如果直接把 12 kHz 与 48 kHz 的
        数据混在一起训练，模型可能学会"看到 48 kHz 就猜正常"，
        得到虚高精度。因此必须：(a) 用与采样率无关的阶次域特征；
        (b) 保留 S_48k（56 个文件、四类齐全、同一采样率）作为干净对照。

  论文用途：任务一"数据情况"小节 + 后续所有消融实验的依据。

图 2  audit_rpm_dist.png —— 转速分布与类别不平衡
--------------------------------------------------------------------------------
结构：左右两个子图。

【左图】标题 "Source rpm distribution"（源域转速分布）
  x 轴  rpm     转速，范围约 1715 ~ 1800
  y 轴  Count   文件个数
  图形  蓝色直方图，共 25 个 bin（每个 bin 宽约 3.4 rpm）
  本次读数：在 1797 rpm 处有一根 41 的高柱；1730 附近、1750 附近、
        1770 附近各有一簇中等高度的柱。
  含义：这四簇正好对应源域的 4 档载荷（0/1/2/3 马力）——载荷越大转速越低。
        载荷 0 对应约 1797 rpm，载荷 3 对应约 1720 rpm。
  重要性：转速跨度只有约 4.6%，因此源域**无法提供低速工况**，
        这正是"目标域 600 rpm 必须靠阶次域去桥接"的原因。

【右图】标题 "Source class imbalance"（源域类别不平衡）
  x 轴  fault type   故障类别 B / IR / OR / N
  y 轴  count        文件个数
  图形  单一橙红色柱状图
  本次读数：OR 77、B 40、IR 40、N 4
  含义：最大类与最小类相差 19.2 倍。N 类只有 4 个文件却只占 2.5%，
        而正常态恰恰是目标域最需要判对的类别 → 任务二必须做类平衡处理
        （Focal Loss、类权重、对 N 做定向增强），主指标用 macro-F1。

  论文用途：任务一数据描述 + 任务二"类别不平衡处理"的必要性论证。

图 3  target_rpm_search.png —— 目标域转速搜索得分曲线
--------------------------------------------------------------------------------
结构：左右两个子图，各自画了 16 条曲线（对应目标域 A~P 共 16 段信号）。
这是"题目说约 600 rpm，到底是不是"的原始证据图。

【左图】标题 "HPS score vs rpm (low-freq shaft harmonics)"
        （HPS 得分随转速变化（低频轴系谐波法））
  x 轴  rpm      候选转速，范围约 510 ~ 690（以 600 为中心 ±15%）
  y 轴  score    HPS 得分 = Σ_{k=1..5} ln(幅值谱在 k×fr 处的值)
                 物理含义：如果某个候选转频 fr 正确，那么 fr、2fr、3fr…
                 这些位置都会同时出现轴系谐波峰，得分就会同时抬高。
  曲线  16 条彩色细线，一色代表一段信号
  黑虚线 600 rpm —— 题目给出的先验值，仅作参考参照
  本次读数：**所有 16 条曲线在 577 rpm 附近同时出现尖峰**（峰高约 40），
        而到 600 rpm 处已回落到 30 上下。
  结论：数据独立地把转速指向 577 rpm 附近，且 16 段高度一致；
        与题目"约 600 rpm"的差异约 4%，属于正常（题目给的是近似值）。

【右图】标题 "Envelope fault-comb score vs rpm"
        （包络故障梳状得分随转速变化）
  x 轴  rpm      同上
  y 轴  score    梳状得分 = 假定故障特征阶次族落在 2.4~5.0 之间，
                 搜索使包络谱上"族内各次谐波能量之和"最大的转频
  曲线  16 条彩色细线
  黑虚线 600 rpm
  本次读数：曲线整体平坦、上下抖动，没有出现明显的单峰
        （显著性 prom 普遍小于 3，最高仅 2.9）。
  结论：**这个方法在本题上失效**，原因是"特征阶次"与"转频"存在耦合
        （阶次 × 转频 = 频率，两者可互换缩放），无法单独确定转频。
        因此最终结果以左图的 HPS 方法为主，本图仅作为对照与说明。

  论文用途：任务一"目标域转速估计"小节；也可用在任务四说明
        "为什么不用无键相阶次跟踪的常规做法"。

图 5 ~ 图 13  verify_order_align_*.png —— 门禁 H1：跨采样率阶次对齐（9 张）
--------------------------------------------------------------------------------
这 9 张图结构完全相同，只有数据与标题中的配对名不同。

  标题  "H1 order alignment: <配对名>"
        配对名 = 故障类型 + 故障尺寸 + 载荷，例：B007_load0
        B = 滚动体、007 = 0.007 英寸、load0 = 载荷 0
  x 轴  order                          阶次（0 ~ 32）
  y 轴  normalized envelope order spectrum
                                       归一化包络阶次谱（各点功率 ÷ 总功率，
                                       所以纵轴数值很小，峰值约 0.005~0.22）
  蓝线  12k_DE 文件（12 kHz 采样、驱动端数据），转速见括号
  橙线  48k_DE 文件（48 kHz 采样、驱动端数据），转速见括号
  黑虚线 theo BSF / BPFI / BPFO=…      该故障类型对应的理论特征阶次
  图例  在右上角，例如 "12k_DE 12kHz 1796rpm"、"theo BPFO=3.58"

  9 张图分别考察：
    图 5~7    B007_load0/1/2，看理论 BSF = 2.36 阶
    图 8~10   IR007_load0/1/2，看理论 BPFI = 5.42 阶
    图 11~13  OR007_load0/1/2，看理论 BPFO = 3.58 阶

  本次读数（以图 11 OR007_load0 为例）：
    在阶次 3.58 处，蓝线与橙线**完全重合**，峰值约 0.22，是整张图的
    最高峰；随后在 7.17、10.7、14.3 阶（即 BPFO 的 2/3/4 次谐波）也能看到
    蓝橙两组峰成对出现。
    而图 5~7（滚动体 BSF）中，蓝橙两线的峰位有 15% 左右的偏移。

  结论与判据：
    判据 rel_gap = |order_12k − order_48k| / theo ≤ 0.05（5%）算通过。
    内圈 IR 中位偏差 0.0000、外圈 OR 中位偏差 0.0005 → 对齐极好；
    滚动体 B 中位偏差 0.1437 → 明显偏移（BSF 本身是轴承里最弱、
    最容易被噪声淹没的特征，属物理限制）。
    总体中位偏差 0.0186 → 判定 **PASS**。

  论文用途：任务一"机理验证"的核心图；也是"为什么用阶次域"的直接证据。
        同时必须注明：**B（滚动体）类的阶次可靠性最低**，
        任务三给出 B 类标签时要单独说明置信度。

图 18  analysis_feature_boxplots.png —— 可迁移特征的类别可分性
--------------------------------------------------------------------------------
结构：2 行 × 4 列 = 8 个子图，每个子图一个特征。
  统一标题 "Source: transferable feature separability by class (12k+48k)"
          （源域：可迁移特征按类别的可分性（12k + 48k））
  每个子图：
    x 轴  fault type   类别 B / IR / OR / N
    y 轴  对应特征的值
    箱线图读法见 0.4（中位线 / Q1-Q3 箱体 / 1.5×IQR 须线 / 离群点已隐藏）

  8 个子图分别是：
    ① t_kurtosis   时域峭度。B/IR/OR 的中位数在 1.6~3.7 之间且分布很宽，
                   **N 类紧贴在 0 附近且几乎无离散** → N 极好区分。
    ② t_crest      峰值因子。同样是 N 类明显偏低（约 4.2），其余三类 4.5~6.5。
    ③ t_rms_rel    按文件归一化后的 RMS。**所有类的中位数都约等于 1.0**
                   （因为定义就是除以本文件的中位数），B 类离散最大，
                   N 类最集中 → 这一列主要反映"窗间稳定性"而非类别差异。
    ④ o_entropy    阶次谱熵。N 类最高（约 5.1，谱最平坦），
                   B/IR/OR 较低（3.5~4.5，谱更尖）→ 判别力强。
    ⑤ o_crest      阶次谱峰值因子。N 类最低（约 45），其余三类 40~80。
    ⑥ o_shaft1     1× 转频阶次处的归一化幅值。OR 类中位数最高、离散最大，
                   说明外圈故障在转频处有更强的调制成分。
    ⑦ o_bandfrac2  阶次 3~6 带的能量占比（BPFO 3.58 与 BPFI 5.42 都落在这里）。
                   OR 最高（约 0.29），N 最低（约 0.26），B/IR 居中。
    ⑧ o_pk0_order  包络阶次谱**最强峰所在的阶次**。IR 类的中位阶次最高
                   （约 4.0，因为内圈故障阶次 BPFI 5.42 最大），
                   B 类离散度最大。**这是互信息最高的特征（0.78）。**

  结论：阶次域特征（④⑤⑥⑦⑧）在类别间呈现出**单调、可解释的差异**，
        而时域特征主要靠"正常 vs 故障"这一条界线（①②）。
        这与 feature_ranking.csv 的排序一致。

  论文用途：任务一"特征分析"的核心图；任务二特征选择的依据。

图 22  timefreq_samples.png —— CWT 时频图样例
--------------------------------------------------------------------------------
  总标题  "CWT time-frequency maps (log magnitude, 64x64, z-scored)"
          （CWT 时频图（对数幅值、64×64、已 z-score 标准化））
  结构    2 行 × 4 列 = 8 个子图
  每个子图：
    x 轴   时间（64 个格，对应 0.5 s 的窗；本图刻度已隐藏）
    y 轴   尺度（对应频率，64 个格，**低频在下、高频在上**，origin="lower"；
           本图刻度已隐藏）
    颜色   viridis 色图：深紫 = 低幅值，蓝绿 = 中等，亮黄 = 高幅值
    数值   对原始信号做 morl 小波的连续小波变换，取模后取 log(1+|CWT|)，
           统一缩放到 64×64，再做 z-score 标准化（均值 0、标准差 1）
           → **只有纹理形态可比，绝对幅值信息已被抹掉**

  上排（源域）：
    src B  (12kHz)   滚动体故障
    src IR (12kHz)   内圈故障
    src OR (12kHz)   外圈故障
    src N  (48kHz)   正常状态（**因为源域 12 kHz 里没有正常样本，
                     自动回退到 48 kHz 的正常文件**）
  下排（目标域）：
    tgt A / B / C / D (32kHz)   真实列车轴承的 4 段

  本次读数：
    源域 IR 子图在**中低频**（图中下部）出现成串的竖直亮条纹 —— 这是内圈
      故障的周期性冲击（每次进入承载区产生一次冲击）；
    源域 OR 子图整体偏暗、纹理平缓 —— 外圈故障的冲击更"均匀"，在此窗内
      不明显；
    源域 N 子图纹理相对弥散、无明显竖条纹；
    目标域 4 张（A~D）普遍在**中低频有较强的竖直条纹结构**，
      形态上更接近源域的 IR/B 子图，而不像 N。

  读图注意（重要）：
    ① 纵轴不是统一的频率刻度。CWT 的尺度换算依赖采样率：
       源域 12 kHz 子图的频率上限取 0.45×12000 = 5400 Hz，
       48 kHz 与目标域 32 kHz 子图的上限取 min(0.45×fs, 6000) = 6000 Hz。
       所以 8 张图的纵轴范围略有不同，**不要直接按像素高度比较频率**。
    ② 本图是**样例演示**，不是任务二训练用的完整数据集。
       需要完整的时频图时执行：

3. 重跑与一致性
================================================================================
  所有图由 `python run.py` 一次生成，共 22 张，总耗时约 30 s（有缓存）。
  run.py 在开始时会执行：
      删除 figures\ 下所有 *.png  →  再按当前配置重新生成
  因此：
    - 不会残留旧配置产生的图；
    - 改了 config.py（如窗长、选带模式、折数）后重跑，图会自动更新。
  单独重跑某一步：
    python data_audit.py            只出图 1、2
    python rpm_estimator.py         只出图 3、4
    python verify_order_domain.py   只出图 5~13
    python analysis_report.py       只出图 18~21
    （注意：单独重跑不会清理 figures\，可能与其他配置的图混在一起，
      推荐始终用 run.py）

4. 读图常见问题
================================================================================
Q1 为什么图里全是英文？
   绘图环境没有中文字体，中文会变成方块。英文标注的含义见本文档逐图说明。

Q2 图 11~13（OR）和图 5~7（B）为什么差别这么大？
   OR（外圈故障）冲击最强、最稳定，在阶次谱上峰最尖锐，12k 与 48k 几乎
   完全重合；B（滚动体故障）本身就是最弱、调制最复杂的特征，峰位会漂移。
   这是物理限制，不是流程错误 —— 但意味着任务三的 B 类标签可信度最低。

Q3 图 4 的柱子看起来一样高，是不是估计没差别？
   不是。y 轴从 0 起，而 16 段的真实差异只有 1%（576~578 rpm）。
   视觉压缩是刻意保留"0 起点"的结果。

Q4 图 19 左图为什么有几个点飞到 PC2 = 600？
   少数窗口包含密集冲击，幅值远超常态，主导了 PCA 的方差方向。
   这也是为什么同时提供了 t-SNE（图 19 右）作为补充。

Q5 图 20 的条形越短越好还是越长越好？
   越短越好。横轴是 |Spearman rho|（与转速的相关强度），
   越接近 0 说明该特征越不受转速影响，越适合跨转速迁移。

Q6 图 21 只画了"最不变"的 12 个，那最偏移的是哪些？
   完整排序见 outputs/domain_shift.csv（按 ks_stat 升序），
   最偏移的是 o_bandfrac2（0.865）、o_pk7_ratio（0.820）、o_pk6_ratio（0.807）。

Q7 图 22 的 tgt A~D 是不是就能看出它们的故障类型？
   不能直接下结论。时频图只提供形态上的定性线索（例如目标域普遍呈现
   较强的中低频竖向条纹），真正的标签判定要等任务三的迁移模型 +
   聚类一致性 + 机理校验三者交叉确认。

Q8 只有 22 张图，但我要在论文里放更多对比怎么办？
   图 18~21 都是由 analysis_report.py 生成的"选优"图（只画前 N 名），
   完整数据在对应的 CSV 里（feature_ranking / feature_rpm_corr /
   domain_shift），可以直接据此画更完整的图。
