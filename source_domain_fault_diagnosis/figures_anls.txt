0.1 五个划分协议（图的横轴/分组几乎都按它分）
    P1  随机文件 5 折，按类别分层            —— 同分布，能力上限
    P2  留一载荷 4 折（载荷 0/1/2/3 各留一次）—— 跨工况
    P3  跨采样率 2 折（12k↔48k 互测，3 类）   —— 跨采样率
    P4  跨传感器位置 2 折（DE↔FE，3 类）      —— 跨轴承型号+传递路径，
                                              最接近"换设备"
    P5  仅 48 kHz 的 56 个文件做 5 折        —— 排除采样率混淆的对照
    注意：P3、P4 因 N 类只在 48 kHz 而**只有 3 类**（B/IR/OR），
          它们的指标**不能与 P1/P2/P5 的 4 类结果直接比大小**。

0.2 五个特征集（图的另一个分组维度）
    F1  全部 91 个特征（时域18 + 频域16 + 阶次37 + 理论阶次20）
    F2  可迁移 49 个（无量纲时域12 + 几何无关阶次37）← 任务三只能用这套
    F3  阶次域 57 个（几何无关37 + 理论阶次20）
    F6  时域 18 个
    F7  频域 16 个（含绝对频率）
    raw_signal  原始 0.128 s 波形（1536 点），只有 cnn1d 模型用它

0.3 七个模型
    lr    逻辑回归
    svm   RBF 核支持向量机（probability=True）
    rf    随机森林（300 棵树，class_weight=balanced_subsample）
    hgb   HistGradientBoosting（300 轮）
    mlp   PyTorch 三层 MLP + Focal Loss
    vote  SVM+RF+HGB 软投票集成
    cnn1d WDCNN 一维卷积网络（输入原始波形）

0.4 主指标 macro-F1
    四类等权平均的 F1。因为 N（正常）只占 2.7%，若用 accuracy 则
    "全判 OR"就能拿 46.7%，毫无意义。**读图时一律优先看 macro-F1。**

0.5 颜色约定
    model_compare / feature_set_compare 里：
        P1 蓝、P2 橙、P3 绿、P4 红、P5 紫（左图按协议着色）
        右图与 feature_set_compare.png 按协议着色：P1蓝 P2橙 P3粉 P4青
    cm_*.png：蓝色深浅 = 样本数（越深越多）
    tsne_P1.png：B 蓝、IR 橙、OR 绿、N 红
    noise_curve.png：蓝线 = 加噪，红虚线 = 干净基线
    permutation_importance.png：青色横条

图 1~5  cm_P1.png ~ cm_P5.png —— 五个协议的混淆矩阵
--------------------------------------------------------------------------------
五张图结构完全相同，只是协议与所用模型不同。

  标题   "P{n} best: {模型} on {特征集}" + 换行 + "macro-F1={值}"
         例："P1 best: hgb on F1  macro-F1=0.903"
         含义：该协议下表现最好的 (模型, 特征集) 组合及其 macro-F1。
         注意：标题里的 macro-F1 是该 (协议,特征集,模型) 在所有折与种子上
              的**均值**。
  y 轴   true        真实标签（B / IR / OR / N）
  x 轴   predicted   模型预测标签
  格子   第 i 行第 j 列的数字 = 真实为 i、被预测为 j 的**窗口数**
         对角线 = 判对的数量，非对角线 = 判错的数量
  色条   右侧 colorbar，数值 = 样本数；颜色越深表示该格样本越多
  行列顺序 按标签数值排序，即 B、IR、OR、N（P3/P4 只有 B、IR、OR）

  【P1】hgb on F1，macro-F1 = 0.903，4×4。四类总数为
        1048(B) + 1037(IR) + 1923(OR) + 112(N) = 4120 ✓
        逐行读数：
          B  真：860 判对，36 误判为 IR，152 误判为 OR，0 误判为 N
          IR 真：79 误判为 B，955 判对，3 误判为 OR，0 误判为 N
          OR 真：148 误判为 B，24 误判为 IR，1751 判对，0 误判为 N
          N  真：0，0，0，112 全对
        要点：① **N 类 112 个窗全部判对**（因为 N 只有 112 个窗，
                且它的峭度/谱熵特征与故障类差别极大）；
              ② 主要错误是 **B↔OR**（152 + 148 = 300 个窗），
                 说明滚动体与外圈的冲击节律在时域特征上容易混；
              ③ 没有任何一类被判成 N，说明模型不会漏报正常为故障。

  【P2】hgb on F1，macro-F1 = 0.957，4×4。这是**全项目最高分**。
        因为 P2 把"载荷"整档留出做测试，而载荷只改变转速（1718~1798 rpm）
        与幅值，特征本身对载荷不敏感，所以掉分很小。
        N 仍为 112 全对。

  【P3】hgb on F3，macro-F1 = 0.673，**3×3**（无 N）。
        读数：B 816/87/145、IR 388/548/101、OR 632/144/1147
        要点：**IR↔B 混淆严重**（388 个 IR 被判成 B）。
             这是跨采样率造成的：12 kHz 与 48 kHz 文件的可用频带不同，
             阶次特征在带选择不同时会漂移。

  【P4】hgb on F3，macro-F1 = 0.497，**3×3**。这是**全项目最低分**。
        读数：B 610/106/152、IR 247/517/104、OR 321/719/487
        要点：① **OR 有 719 个窗被判成 IR**（OR 真共 1527 个窗，
                 判对只有 487），说明换设备后外圈特征被完全打乱；
              ② 三类互相都大量混淆，矩阵接近"均匀铺开"，
                 意味着模型几乎没有学到可迁移的判别边界；
              ③ 这张图是**任务三最重要的风险预警**：
                 P4 同时换了轴承型号（SKF6205→6203）与传递路径，
                 是最接近真实列车场景的协议，它只有 0.5 分。

  【P5】rf on F7，macro-F1 = 0.891，4×4。只用 48 kHz 的 56 个文件。
        要点：与 P1 的 0.903 差距仅 0.012 → **说明 P1 的高分不是靠
             "采样率"作弊得来的**，任务一担心的混淆风险被排除。

图 8  tsne_P1.png —— P1 训练/测试集特征的二维分布
--------------------------------------------------------------------------------
画布为 1 行 2 列，两个子图共享同一套 t-SNE 坐标（左边训练集点与右边测试集点
是同一次降维的结果，因此两张图的点可以直接对照）。

  【左】标题 "train fold features (P1/F2) by class"
        取 P1 第 1 折的训练集，随机抽 1500 个窗
  【右】标题 "test fold features by true class"
        取同一折的全部测试集窗（约 850 个）
  x/y 轴  t-SNE 1 / t-SNE 2，**已隐藏刻度**
         t-SNE 是无监督非线性降维，坐标**没有物理单位**，
         只能看"是否成团 / 是否重叠"，不能按数值大小解读
  颜色    B 蓝、IR 橙、OR 绿、N 红（图例右上）
  参数   perplexity=30、max_iter=800、init='pca'、learning_rate='auto'、
         n_jobs=1、random_state=0（保证可复现）
  输入   49 个可迁移特征，先做 RobustScaler（减中位数、除四分位距）

  本次读数：
    左图（训练）：B（蓝）与 IR（橙）大面积交叠，OR（绿）散在外围形成多个
      小簇，N（红）在右上角聚成一小团、相对独立。
    右图（测试）：结构与左图一致 —— 同样的交叠、同样的外围绿簇、
      同样的右上红团。**这印证了 P1 是"同分布"划分**：测试集没有落在
      训练集看不到的区域。
  要点：N（红）虽然只有 4 个文件 112 个窗，但在特征空间里自成一小簇、
        与其它类分离，这解释了为什么 N 类在 P1 下能全判对。
        而 B 与 IR 的交叠正是混淆矩阵里 B↔IR 错误（79 + 36 个窗）的来源。

        t_kurtosis    0.079   时域峭度（冲击性）

图 10  noise_curve.png —— 加噪鲁棒性（结论不可靠，务必谨慎引用）
--------------------------------------------------------------------------------
  标题  "Noise robustness"
  x 轴  SNR (dB)，**已反转**（左 20 dB → 右 0 dB），即从左到右噪声越来越强
  y 轴  macro-F1
  蓝线 + 误差棒  加噪后各 SNR 的 macro-F1（误差棒 = 5 折标准差）
  红虚线 + 图例 "clean baseline"  未加噪时的 macro-F1（0.556）
  配置  协议 P1、特征集 F2、模型 svm
  做法  对原始信号加高斯白噪声（噪声功率 = 信号功率 / 10^(SNR/10)），
        再用任务一的同一套代码重新提取特征，最后用同一配置评估

  本次读数：
        clean  0.556 ± 0.142
        SNR20  0.408 ± 0.111
        SNR10  0.651 ± 0.081
        SNR 5  0.620 ± 0.071
        SNR 0  0.442 ± 0.063

  ★ 读图警告：曲线**非单调**（20 dB 反而最差、10~5 dB 反而比干净数据还好），
    这在物理上说不通。原因是指标口径问题，不是真实效应：
      ① macro-F1 在 N 类上极不稳定 —— N 每个测试折只有 **1 个文件**
         （约 31 个窗），这一个文件判对或判错会让 f1_N 从 1.0 变成 0，
         直接把 macro-F1 拉动 0.25；
      ② 标准差高达 0.14，说明折间波动远大于 SNR 带来的差异。
    因此**这张图目前不能作为"模型抗噪能力强弱"的结论**，
    只能作为"指标不稳定"的证据。要得到可用结论需改用文件级指标，
    或想办法扩充 N 类样本（源域仅 4 个正常文件，这是硬约束）。

4. 常见疑问
================================================================================
Q1 为什么 P3/P4 的混淆矩阵是 3×3，其它是 4×4？
   N 类（正常）的 4 个文件全在 48 kHz 目录，P3（按采样率切）与
   P4（按 12k 下的 DE/FE 切）无论怎么分都会有一侧缺 N，因此降为 3 类。

Q2 为什么 P2 的分数比 P1 还高？
   P1 是随机切，训练/测试里都混着四类；P2 是按载荷整档留出，而载荷只改变
   转速与幅值，对已归一化的特征影响很小，相当于"测试集更同质"，
   所以分数反而更高。这**不**说明 P2 比 P1 更容易，只说明载荷不是主要域差异。

Q3 图 7 里 raw_signal 只有两根柱？
   M5（原始信号 WDCNN）按 roadmap 只跑了 P1 与 P2 两个协议，见
   results/runs_cnn1d.csv。

Q4 为什么图 9 里大部分阶次特征重要性接近 0？
   P1 是同分布划分，此时"绝对幅值/冲击统计量"最有效，阶次特征提供的是
   与转速无关的信息，在同分布下属于冗余。要看阶次特征的价值必须看
   P4（跨设备），见 results/group_ablation.csv。

Q5 图 6 的左图为什么 y 轴标签是 "P1/cnn1d" 这种合并形式？
   它把"协议"和"模型"两个维度压到一根柱上，便于在一张图里比较所有
   (协议, 模型) 组合；每个标签取的是该组合在**所有特征集**上的最好成绩。

Q6 图 8 的 t-SNE 坐标能给出数值含义吗？
   不能。t-SNE 只保留局部邻域结构，点间距离和坐标轴都无物理意义，
   判断"两类是否可分"要看它们是否形成互不重叠的团。
